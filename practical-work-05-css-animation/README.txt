Контрольные вопросы:

1. В чём разница между transition и animation?
Ответ: transition плавно изменяет свойства при переходе между состояниями, например при hover. animation позволяет создавать последовательность изменений с помощью @keyframes.

2. Какие свойства можно анимировать в CSS?
Ответ: Можно анимировать многие числовые и цветовые свойства, например color, background, opacity, transform, width, height и другие.

3. Для чего используется transform?
Ответ: Для перемещения, масштабирования, поворота и других преобразований элемента.

4. Как задать плавность анимации?
Ответ: С помощью transition или функции времени animation-timing-function, например ease или linear.

5. Что означает параметр infinite?
Ответ: Анимация будет повторяться бесконечно.

6. Как задать задержку перед началом анимации?
Ответ: С помощью свойства animation-delay.

7. Чем отличаются функции времени ease, linear, ease-in-out?
Ответ: Они задают разную скорость изменения: ease ускоряет и замедляет движение, linear сохраняет одинаковую скорость, ease-in-out плавно ускоряет и замедляет движение.

8. Можно ли объединять несколько анимаций для одного элемента?
Ответ: Да, несколько анимаций можно указать через запятую в свойстве animation.

9. Как работает свойство animation-iteration-count?
Ответ: Оно задаёт количество повторений анимации. Можно указать число или infinite.

10. Какие плюсы и минусы CSS-анимаций по сравнению с JavaScript-анимациями?
Ответ: CSS-анимации проще для стандартных визуальных эффектов и обычно хорошо работают в браузере. JavaScript даёт больше контроля над сложной логикой и взаимодействием, но требует больше кода.
